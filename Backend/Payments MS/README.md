# Payments Service

## Overview

The **Payments Service** is a microservice responsible for handling payment transactions securely and efficiently. It supports multiple payment methods and integrates seamlessly with external payment gateway. This service is designed to be highly extensible, enabling businesses to customize it to their needs.
---

## Key Features

- **Integration with Payment Gateways**: Connects with Stripe provider.
- **Multi-Currency Support**: Handle payments in various currencies with real-time exchange rate updates.
- **Failed Payment Handling**: Automatic retries and failure logging for incomplete transactions.
