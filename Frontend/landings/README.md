# HandyParking - Landing Pages

This repository contains the landing pages for the HandyParking application - a solution designed to make parking effortless and efficient.

## Repository Contents

This repository contains three landing pages for the HandyParking application:
- Main landing page (`index.html`)
- Driver-focused landing page (`driver.html`)
- Parking spot owner landing page (`owner.html`)

These landing pages showcase the application's features and benefits for different user types.

## Project Structure

- `src/` - project source code
    - `index.html` - main page
    - `driver.html` - page for drivers
    - `owner.html` - page for parking lot owners
    - `styles/` - CSS styles
    - `images/` - project images
